# Defect report template

Record a defect only after reproducing it and checking the expected contract for the target version.

- Title and case ID
- Severity and user impact
- Target version, configuration, test run, and timestamp
- Preconditions and synthetic data used
- Steps, with request bodies and sanitized responses
- Expected result and contract reference
- Actual result and frequency
- Relevant state before and after the request
- Redacted evidence and retest status

This repository does not claim an upstream defect based on fixture behavior.
